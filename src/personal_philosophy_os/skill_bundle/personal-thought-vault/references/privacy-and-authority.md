# 权限与隐私

## 权限

AI 可以：

- 提议根问题映射；
- 生成候选原则、案例和修订建议；
- 说明证据缺口和可能的冲突。

只有 Vault 所有者可以：

- 确认或否决映射、原则和案例；
- 修改一级根问题；
- 接受或拒绝外部观点；
- 授权模式切换和正式写入。

## 隐私

- 第三方使用主体 ID 或化名。
- 只读取完成当前任务所需的最少记录。
- 不在 Git、Issue、CI 日志或公开对话中粘贴 Vault 原文。
- 不把绝对路径、联系方式、地址、单位或秘密写进诊断输出。
- 原始影子答案不进入 Git；只有经人工确认的脱敏摘要与内部 ID 才可归档。
- 不创建私人 Vault 副本，不自动同步，不自动提交。

## 外部思想隔离

外部来源只能进入来源层。AI 的概括放 agent interpretation，用户逐字解释放 owner interpretation。除非用户明确裁决，状态保持候选。

## 写隔离

多智能体环境中，每个 Agent 只写自己的 staging。正式合并由单点验证器执行，整批校验失败时不得部分写入。
