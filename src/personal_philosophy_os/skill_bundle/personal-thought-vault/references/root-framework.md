# 根问题与五模块

## 默认一级骨架

| ID | 根问题 |
|---|---|
| root-00 | 待归区：现在还不知道它属于哪里 |
| root-01 | 我是谁，我愿意成为什么样的人？ |
| root-02 | 我如何与他人相处，同时不失去自己？ |
| root-03 | 我如何面对痛苦、不确定和失去？ |
| root-04 | 我如何选择，并承担选择的代价？ |
| root-05 | 我如何成长、行动和修正自己？ |

一级骨架是默认模板，不是永恒真理。只有 Vault 所有者能增删改；AI 只能根据长期待归证据提出建议。

每条映射有一个主根和零到配置上限个次根。待归根不得作为次根；主根为待归时，次根必须为空，猜测只进候选根且不参与正式路由。

## 五个模块

### 核心原则

原则必须回到用户自己的证据，包含适用条件、极端化代价、相反原则、修订历史和使用案例。AI 只能创建候选，只有用户能确认。

### 问题案例

一事一档，保留最少事实、责任、边界、动机、代价、行动、结果、可迁移信号和失效条件。按认知结构匹配，不按人物或关键词硬配。

### 外部来源

外部原文、AI 释义与用户解释分字段保存。关系只能是支持、挑战、工具或待验证。读过、引用和使用都不等于认同。

### 决策反思

固定分开：当时事实、当时判断、行动、预期、真实结果、有效与失真、修订提案。结果好不自动等于判断对，结果坏不自动等于判断错。

### 辩论修订

辩论只生成收窄条件、补极端代价、建立相反原则或维持原判的建议。未经用户裁决，不修改原则。

## 思想网络

网络是现有正典的派生视图，不建立第二套事实库。允许的关系是：属于、支持、相斥、应用于、修订自、外部呼应。
