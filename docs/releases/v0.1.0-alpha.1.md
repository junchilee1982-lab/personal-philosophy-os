# v0.1.0-alpha.1

Personal Philosophy OS 的第一个公开预发行版。

## 亮点

- 按人生根问题而不是知识来源组织个人思想。
- 原子证据与根问题映射分离，允许重构骨架而不改写原话。
- AI 只能提案，人类拥有根问题、映射、原则和外部观点的最终确认权。
- 提供空 Vault 初始化、结构校验、证据/原则检索、根问题上下文和显式模式切换。
- 可将同一技能安装到 Codex 与 Claude Code，并进行受控卸载。
- 无运行时第三方依赖、默认不联网、无遥测。

## 隐私

Release 只包含通用引擎、Agent Skill、Schema、空模板和标记为 synthetic 的虚构示例，不包含任何真实个人 Vault 数据。

## 安装

```bash
git clone https://github.com/junchilee1982-lab/personal-philosophy-os.git
cd personal-philosophy-os
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
ppos init --vault "$HOME/.personal-philosophy-os/vault" --demo
ppos skill install --target both
```

## 已知限制

- Alpha 暂不自动执行大批量提卡、旧库迁移、夜间流水线、云同步或模型调用。
- 候选映射和原则成为正式记录前仍需人工裁决。
- Python API 在预发行期间可能继续收窄；升级前请查看 Changelog。
