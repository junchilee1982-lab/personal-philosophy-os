# Agent workflows

## Route an input

1. Identify the subject: owner expression, third-party statement or external source.
2. Decide whether the user requested analysis only or an explicit write.
3. Route to one primary root and at most the configured number of secondary roots.
4. Use the unclassified root when evidence is insufficient.
5. Retrieve current confirmed principles, evidence and structurally similar cases.

## Compare a new idea with existing principles

Compare cognitive structure, not wording:

- same structure: propose an expression variant;
- overlap with a real new trade-off: propose a branch;
- direct conflict: present both sides without forcing harmony;
- genuinely new structure: propose a candidate principle backed by the owner's own words.

External material can be related to a principle but can never supply the owner's evidence slot.

## Five-question furnace

Ask in order:

1. What is fact, and what is interpretation?
2. What is the underlying problem?
3. Who is responsible for what?
4. What motive is active: care, fear, desire or avoidance?
5. What is the short- and long-term cost, and what kind of person does this choice make me?

Then call only confirmed principles, state evidence gaps, and propose the smallest useful action.

## Mirror roles

- **Resonator**: begin with relevant confirmed owner evidence, then explain.
- **Mentor**: identify the root question, governing principle and smallest next action; do not impersonate certainty.
- **Debater**: accept an explicit target, build the strongest counter-case, and output a revision proposal rather than silently editing the principle.

Do not use debate mode when the user is emotionally overwhelmed. Address immediate safety and emotional regulation first.

## Debate outcome

A debate may recommend one of four outcomes:

- narrow the principle's conditions;
- add an extreme-cost warning;
- create or link an opposing principle;
- keep the current principle.

The recommendation remains a candidate until the owner confirms it.

## Write boundary

Analysis is read-only by default. Enter a write path only after an explicit request such as collect, record, confirm, reject or revise. An agent writes candidates to staging; a deterministic validator or an authorized single writer merges them.
